Harbor Spot is an original spot-the-difference game: two near-identical pictures side by side, seven differences per scene across three hand-drawn scenes (Harbor Sunset, Cozy Café, Night Garden), a countdown timer, score and combo, hints, and win/lose screens. Click a difference on either picture to ring it in green; a wrong click costs 5 seconds. Every scene is drawn in code with canvas 2D — no copied art, no network, no build step.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Play with mouse and keyboard: click a difference on either picture, `H` hint, `P` pause, `R` restart, `1`/`2`/`3` jump to a scene, `Esc` menu. Deterministic screenshots: `?shot=start|play|end&seed=1`.
